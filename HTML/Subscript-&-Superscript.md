# Tags

## 1. Big Tag

Big tag makes the size of text big.

```html
<big>This tag shows big text</big>
```

## 2. Small Tag

Small tag makes the text small in size.

```html
<small>This tag shows small text</small>
```

## 3. Hr Tag

Hr tag is used to separate content and add a line

```html
<hr />
```

## 4. Line Break

br is for line break

```html
<br /><br />
```

## 5. Subscript and Superscript Tags

Subscript tag `<sub>`: Displays text slightly below the normal line.

Superscript tag `<sup>`: Displays text slightly above the normal line.

#### Examples

##### `<sub>` H2O

```html
H<sub>2</sub>O
```

##### `<sup>` 3 raised to the power 2

3<sup>2</sup> = 9

## 6. Super and Sub Script

```html
This is an <sup>example of superscript text</sup> and this is
<sub>an example of subscript text</sub>
```
