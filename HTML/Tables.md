# Tables

- **`th`** = table heading
- **`td`** = table data
- **`tr`** = table row
- **`tbody`** = table body

## `Example`

```html
<table>
  <caption>
    Students Data
  </caption>

  <thead>
    <tr>
      <th>Name</th>
      <th>Roll No</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>Areeba</td>
      <td>164</td>
    </tr>
    <tr>
      <td>Meerub</td>
      <td>120</td>
    </tr>
    <tr>
      <td>Ibrahim</td>
      <td>130</td>
    </tr>
  </tbody>
</table>
```

**Students Data**

| Name    | Roll No |
| ------- | ------- |
| Areeba  | 164     |
| Meerub  | 120     |
| Ibrahim | 130     |
