# ID & Classes

## ID
id is used to uniquely identify one specific element on the page.  

It can be used only once in the whole HTML document.  

In CSS, we write it like `#myId`.

---

## Class
class is used to group multiple elements together that share the same styling or behavior.  

You can use the same class on many elements.  

In CSS, we write it like `.myClass`.

---

### Symbols for Class and ID
`.` is for class and `#` is for id.

---

## Example of Class
The element having this class will have a all the properties  class redBg have
```html
<span class="redBg">This is a class example</span>
```
## Example of ID
Id is a unique elemennt, it can only be applied to one element as it is unique.

```html
<span id="mainspan">This is an ID example</span>
```

## Comparison Table

| Feature     | id                              | class                              |
| ----------- | ------------------------------ | ----------------------------------- |
| Usage       | Unique (one element only)       | Reusable (multiple elements)       |
| CSS Syntax  | `#idName`                       | `.className`                       |
| Purpose     | Identify a specific element     | Style/group multiple elements      |
