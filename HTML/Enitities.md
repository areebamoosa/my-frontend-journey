# HTML Entities

To display symbols like `<`, `>`, `£`, etc., we use **HTML entities**.

---

## Example 1: Displaying `<p>` tag using entities

```html
<p>The HTML tag &lt;p&gt; is written like this using entities.</p>
```

- `&lt;` is for <

- `&gt;` is for >

## Example 2: Displaying the pound `£` currency symbol

```html
<p>The pound currency symbol is written like this: &pound;</p>
```

- `&pound;` displays £

## Common HTML Entities Reference

| Entity Code | Symbol  | Description               |
| ----------- | ------- | ------------------------- |
| `&lt;`      | <       | Less than                 |
| `&gt;`      | >       | Greater than              |
| `&amp;`     | &       | Ampersand                 |
| `&quot;`    | "       | Double quotation mark     |
| `&apos;`    | '       | Apostrophe / single quote |
| `&nbsp;`    | (space) | Non-breaking space        |
| `&copy;`    | ©       | Copyright symbol          |
| `&reg;`     | ®       | Registered trademark      |
| `&trade;`   | ™       | Trademark symbol          |
| `&euro;`    | €       | Euro currency             |
| `&pound;`   | £       | Pound currency            |
| `&yen;`     | ¥       | Yen                       |
