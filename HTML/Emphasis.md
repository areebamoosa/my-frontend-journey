# EMPHASIS TAGS IN HTML

In HTML, emphasis tags are used to highlight or give importance to text.  
The main emphasis tags are:

#### 1. `<em>` (Emphasis)

Used for emphasized text.  
Usually displayed in italic by default.

##### Example:

```html
<p>This is <em>important</em> information.</p>
```

#### 2. `<strong>` (Strong Emphasis)

Used for strongly emphasized text.  
Usually displayed in bold by default.  
##### Example:

```html
<p>Please <strong>do not</strong> touch the wires.</p>
```

#### 3. `<i>` (Italic)

Used for styling text in italics.  
##### Example:

```html
<p>This is <i>italicized</i> text.</p>
```

#### 4. `<b>` (Bold)

Used for styling text in bold.  
##### Example:

```html
<p>This is <b>bold</b> text.</p>
```

---

### **HTML FORMATS**

#### `<u>` (Underline)

To underline a text we use `<u>` tag.  
##### Example:

```html
<u>Lorem ipsum dolor sit amet consectetur adipisicing elit. Quibusdam, vero?</u>
```

#### `<s>` (Strikethrough - No Meaning)

Used to strike through text (visually).  
Default rendering: strikethrough.  
##### Example:

```html
<p>The old price was <s>$50</s>, now it's $30!</p>
```

#### `<ins>` (Inserted - Semantic Meaning)

Represents newly inserted text.  
Usually underlined by default.  
##### Example:

```html
This feature is <ins>now available</ins> for all users.
```

#### `<big>` and `<small>` tags

##### Example:

```html
<small>Lorem ipsum dolor sit amet.</small> <big>Lorem, ipsum.</big> Lorem ipsum
dolor sit amet.
```

#### `<address>` tag

The address tag gives fonts automatically.  
##### Example:

```html
<address>
  <p>House NO : KKK</p>
  <p>PAF Base</p>
  <p>Karachi</p>
</address>
```
