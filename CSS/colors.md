# COLOURS

## HTML Structure

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>COLOURS</title>
    <style>
      /* Colors */
      #firstpara {
        color: pink;
      }
      /* RGB Colors */
      #secpara {
        color: rgb(91, 24, 167);
      }

      /* Hex Colours */
      #thirdpara {
        color: #ff88ff;
      }
    </style>
  </head>
  <body>
    <h3>COLOURS IN CSS</h3>

    <p id="firstpara">This is a Paragraph</p>

    <p id="secpara">This is a Paragraph</p>

    <p id="thirdpara">This is a Paragraph</p>
  </body>
</html>
```

## Output in Browser

### COLOURS IN CSS

* **First Paragraph** → Pink color
* **Second Paragraph** → RGB(91, 24, 167) color
* **Third Paragraph** → Hex `#ff88ff` color
