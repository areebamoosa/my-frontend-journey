# Display Property

The display property controls how an HTML element looks and behaves on the page — like how it sits, how it flows, and how it interacts with other elements.

### Common display values:

**block:** Takes full width — starts on a new line

**inline:** Stays in line with text — takes only as much space as needed

**inline-block:** Like inline, but you can set width/height

**none:** Hides the element completely

**flex:** Makes a flexbox container for easy layout control

**grid:** Makes a grid layout container

#### Examples:

`block:`

<p>This is a paragraph</p>

➡ Paragraphs are block elements — they go on a new line.

`inline:`
<span>This is a span</span>

➡ Spans are inline — they stay within the same line as the text.

`inline-block:`
Let’s you treat something like a button or image — in-line with size control.

`none:`

Totally hides the element like it doesn’t exist on the page.
